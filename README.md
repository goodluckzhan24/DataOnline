# DataOnline · 当日工作清单

一个**纯 HTML 单文件**的每日工作记录页面，无需后端、无需安装，双击 `index.html` 即可使用。

## 功能

- ✍️ **添加工作项**：日期、项目名称、工作内容、用时（小时）、状态（待办 / 进行中 / 已完成）、备注
- ✏️ **编辑 / 删除**：随时修改或删除已添加的条目（删除有确认弹窗）
- 📅 **按日期筛选**：默认显示今天，可切换任意日期或查看全部
- 📊 **统计**：顶部实时显示今日条数、今日用时、累计条数、累计用时
- 📤 **导出 JSON**：一键导出「当日」或「全部」记录为 `.json` 文件备份
- 📥 **导入 JSON**：导入之前导出的文件，支持「合并」或「覆盖」两种方式
- 💾 **本地保存**：数据存在浏览器 `localStorage`，关闭页面不丢失

## 使用方式

### 本地使用
直接用浏览器打开 `index.html` 即可。

### 在线使用（GitHub Pages）
仓库 Settings → Pages → 选择 `main` 分支 / 根目录，开启后访问：
`https://goodluckzhan24.github.io/DataOnline/`

## 注意事项

- 数据仅保存在**当前浏览器**中：换浏览器、清除浏览器数据都会丢失记录，请定期「导出全部 JSON」备份。
- 导出的 JSON 结构：

```json
{
  "app": "daily-work-log",
  "version": 1,
  "exportedAt": "2026-08-30T00:00:00.000Z",
  "count": 1,
  "items": [
    {
      "id": "xxx",
      "date": "2026-08-30",
      "project": "项目名称",
      "content": "工作内容描述",
      "hours": 2.5,
      "status": "done",
      "note": "备注",
      "createdAt": "...",
      "updatedAt": "..."
    }
  ]
}
```
